# ReviewHub Student Review Platform

This is a static Bootstrap-based website prototype for a graduation project.

## Pages

- `index.html`: Home page, school search, school matching results
- `professors.html`: Professor search, results, reviews, rating form
- `programmes.html`: Programme search, results, reviews, rating form
- `register.html`: Register school/professor/programme with Bootstrap tabs
- `contact.html`: Contact form, imprint, image sources

## Requirements covered

- HTML headers and semantic structure
- Navigation menu with internal page links and on-page links
- Bootstrap classes plus custom CSS
- Images with alt text
- Contact form
- Image source references
- Consistent colour palette
- Accessibility support: hierarchical headings, alt text, ARIA labels, skip link
- Imprint section
- Small JavaScript gadgets: search reveal, star rating, review sorting, contact alert

## Deployment

Upload the full folder to GitHub, then enable GitHub Pages from the repository settings.
